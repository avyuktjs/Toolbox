# Changelog

## [0.1.0] — 2026-11-17

Initial release.

- 14 tools on one tab: media downloader, media converter, JSON formatter,
  Base64, case converter, word counter, UUID generator, contrast checker,
  QR generator, URL encoder, hash generator, timestamp converter, text diff,
  lorem ipsum
- yt-dlp-backed downloader with selectable container/resolution/bitrate
- FFmpeg-backed converter with custom CRF
- History kept in `localStorage`, expires with the files
- CI: lint, type-check, build on every push
