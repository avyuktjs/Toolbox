# Code of conduct

This is a small project. The rules are short:

- Be decent. No insults, no harassment, no hostility.
- Critique code, not people.
- Respect the honest-output rule in `CONTRIBUTING.md` — don't push dishonest
  features, even framed as "just visual".
- If something here isn't working for you, open an issue; if it's a conduct
  issue, email **vj07072010@gmail.com**.

Violations get a warning first, then removal from the repo. That's it.
